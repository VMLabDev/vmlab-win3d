# vmlab-win3d

A driver package for Windows guests running under vmlab. Install it in a
Windows 10 or 11 guest and Direct3D 9 to 12 and OpenGL applications run
hardware-accelerated with no per-application setup. The rendering runs on the
Vulkan stack of the host running QEMU, through virtio-gpu Venus.

Status: not started. See `docs/brief.md`.
